# H4K8ac in adult oligodendrocyte progenitors: an end-to-end reanalysis

Independent reanalysis of public data from Dansu\*, Selcen\* et al. (2024),
*J Cell Biol* 223(11):e202308064, starting from raw reads.

- RNA-seq: GSE263808 (O4+ OPCs; P5 vs P60; DMSO, KATi, SUV420i),
  GSE66047 (PDGFRα+ P2), GSE122446 (PDGFRα+ P60)
- H4K8ac ChIP-seq: GSE240522 (PDGFRα+ OPCs; P5 vs P60; matched inputs)

Status: work in progress.
